Compressor verkleinert Bilddateien wahlweise durch Dateikompression oder Änderung der Bildabmessungen und speichert die Dateien im Download-Verzeichnis.

Die Browserbasierte Web-App ​Compressor komprimiert Bilddateien auf eiben einzugebenden Zielwert. Dabei kann gewählt werden, ob die Dateigröße durch jpeg-Komprimierung oder durch Verringerung der Bildabmessungen (z.B. für png) erreicht wird. 

# ​Funktionen im Überblick
**Zielgröße und Methode:**
Die gewünschte Größe der komprimierten Datei kann eingegeben werden. Kompression oder Verringerung der Bildgröße kann ausgewählt werden.

**​Export der komprimierten Bilder**: Als einzelne Dateien oder Zip-Download unter dem identischen Quelldatei-Namen (!) ins Download-Verzeichnis.
